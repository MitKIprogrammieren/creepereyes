CreeperEyes Webflash

Animierte Augen für den Frankenstein-Kopf auf dem Waveshare ESP32-H2-DEV-KIT-N4 mit zwei Waveshare 1,5"-OLEDs – grau oder farbig.

Firmware installieren

1. Display wählen

2. Flashen

Dein Browser kann keine USB-Geräte ansprechen. Bitte Chrome oder Edge am Computer verwenden.

Webflash funktioniert nur über HTTPS.

Vorher den LiPo abziehen – es darf nur eine Stromquelle aktiv sein.

So geht's

  1. Board über seine USB-C-Buchse mit dem Computer verbinden.
  2. Auf den Button klicken und den Port mit CH343 im Namen auswählen.
  3. Das Löschen bestätigen und warten, bis 100 % erreicht sind.
  4. Einmal RESET drücken – die Augen starten.
  5. Klappt die Verbindung nicht: BOOT halten, RESET drücken und loslassen, dann BOOT loslassen.

Bauanleitung

Teile

  • Waveshare ESP32-H2-DEV-KIT-N4
  • 2 × Waveshare 1.5inch OLED Module (grau, SSD1327) oder 1.5inch RGB OLED Module (farbig, SSD1351)
  • TP4056-Lademodul mit USB-C und Schutzschaltung (6 Pads)
  • LiPo 1S 3,7 V mit JST-Stecker
  • Litze ca. 0,25 mm², gedruckter Frankenstein-Kopf

VCC, GND, DIN, CLK, DC und RST gehen an beide OLEDs, CS jeweils nur an eines. BS1 und BS2 am OLED auf 0 lassen (SPI).

Die USB-C-Buchse des TP4056 kommt an die Rückseite des Kopfes. Rote LED = lädt, blaue LED = voll. Zum Ausschalten den JST-Stecker ziehen.

Basierend auf CreeperEyes von Joshua Marker und Adafruits „Uncanny Eyes“, Kopf von Printables. Geflasht wird mit ESP Web Tools.
